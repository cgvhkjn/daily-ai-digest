# 每日 AI 日报 · Daily AI Digest

每天早上 10:00（北京时间）更新一期：**AI 界热门资讯约 5 条 + GitHub 热门项目约 5 个 + 一句今日重点**，5 分钟读完。

- 在线看：打开本仓库的 `index.html`（或启用 GitHub Pages 后在线浏览），最新一期在最上面，往期可切换。
- 存档看：每一期都以 Markdown 存在 [`digests/`](digests/) 目录里，按日期命名。
- 方法说明：这份日报是怎么选稿、怎么核实的，见 [METHOD.md](METHOD.md)。想做一份同款日报，把那份规范交给你的 AI 助手按时执行即可。

## 选稿原则（摘要）

1. 资讯优先过去 24 小时，一手来源优先（官方博客、官方公告、论文原文），核对发布日期，绝不拿旧闻充数。
2. GitHub 项目以 Trending 为准，Star 数逐个从仓库页或 API 核实，绝不估算；官方不存历史榜单时注明数据口径。
3. 传闻单独隔离成「传闻观察」栏，明确标注未经证实，绝不混进正式资讯。
4. 与前几天去重：同一条资讯、同一个项目不连续多天重复，除非有实质性新进展。
5. 某个板块没有可信新内容时如实写“今日暂无”，不用低质量内容凑数。

完整规范见 [METHOD.md](METHOD.md)。
