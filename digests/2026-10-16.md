## AI 热门资讯

### 1. Meta 发布 Muse Spark Open 开源权重模型
Meta 称它是目前最强的美国开源权重模型：总参数 816B、激活 42B、上下文 100 万 token，原生多模态，主打编程和 Agent 长任务；还专门针对 Mac Studio（M5 Ultra）做了优化，强调能在桌面端本地跑。昨天日报里刚讲完前沿模型打价格战，今天 Meta 直接把权重放出来，桌面本地 Agent 要热闹了。
（来源：TechCrunch 等，2026-10-15）

### 2. Anthropic 向外部评估机构 METR 开放“员工级”访问
据 Reuters 报道，Anthropic 让独立评估组织 METR 以接近内部员工的权限去测试它的模型。厂商把第三方评估做到这个深度不多见，这是把“安全可信”当竞争筹码打。
（来源：Reuters，2026-10-15）

### 3. 苹果国行 AI 有新进展：库克确认 10 月底开启测试
这是昨天那条的后续更新：不再是“有望 12 月”，库克确认 Apple Intelligence 国行版 10 月底开启测试，接入阿里通义千问；但新版 Siri AI 仍不在首波范围内。
（来源：新浪 / 财联社，2026-10-15）

### 4. OpenAI 推出 Rosalind 学术计划
OpenAI 把它的生命科学方向模型 Rosalind 向高校和学术机构开放了专门计划。生命科学正在成为各家抢的垂直高地，对做科研的人值得留意后续细则。
（来源：WiseVoter，2026-10-15）

### 5. Webflow 上线与 Google Gemini 的连接器
建站平台 Webflow 发布了与 Gemini 的官方连接，让企业在建站和运营流程里直接调用 Gemini 的能力。大模型的竞争越来越不在模型本身，而在谁先嵌进现成的工作流入口。
（来源：GlobeNewswire，2026-10-15）

## GitHub 热门项目

1. **[anthropics/claude-plugins-official](https://github.com/anthropics/claude-plugins-official)** · ⭐ 39,161 · Python
   Anthropic 官方维护的 Claude Code 插件目录。用 Claude Code 的话，这是官方精选入口，值得挨个翻。

2. **[JuliusBrussee/caveman](https://github.com/JuliusBrussee/caveman)** · ⭐ 112,596 · Go
   思路很野：让编程 Agent 用“原始人说话”的极简方式交流，号称能砍掉 65% 的 token 消耗。荒诞但戳中了真痛点，所以爆了。

3. **[obra/superpowers](https://github.com/obra/superpowers)** · ⭐ 299,937 · Shell
   一套 Agent 技能框架加软件开发方法论，把“怎么让 Agent 靠谱地写代码”做成了可复用的技能包。

4. **[ruvnet/ruflo](https://github.com/ruvnet/ruflo)** · ⭐ 75,155 · TypeScript
   多 Agent 集群的调度框架：部署智能体群、协调自主工作流，带自适应记忆和 RAG 集成，原生支持 Claude Code、Codex 等。

5. **[affaan-m/ECC](https://github.com/affaan-m/ECC)** · ⭐ 280,437 · JavaScript
   给 Agent 框架做性能优化的系统：技能、本能记忆、安全与研究优先的开发流程，覆盖 Claude Code、Codex、Cursor 等多个平台。
