# 每日 AI 日报 · 2026-10-17（正式版）

**今日重点：** 今天的主线是“定规则”：中国拟把顶级模型纳入出口管制草案，Anthropic 则把自己的监管草案推向美国国会，模型再强也要先过规则这一关。

## AI 热门资讯

### 1. 中国公布 AI 技术出口管制修订草案，开源发布设快速通道
草案拟将 23 项关键 AI 技术纳入管制，涵盖大模型、智能代理、算力集群与数据处理；达到超高训练算力、超大参数或全球排名靠前的模型，其权重、源码与训练方法等核心技术出口将受限。同时草案为开源发布设了自动许可的快速通道，已公开的技术不受新规限制，显示管制与保住开源生态在同时推进。
（来源：流動日報 NewMobileLife，2026-10-17）

### 2. Anthropic 向美国国会推介 AI 监管草案，主张只在严重风险时叫停模型
据 POLITICO 报道，Anthropic 已向国会议员推介一份前沿 AI 安全与防务法案草案，主张只有在可能造成巨额经济损失或重大伤亡、且风险来自生物武器、模型失控或严重网络攻击等情形时，政府才能叫停模型发布或使用；草案同时要求实验室建立安全框架、发透明度报告并向商务部通报重大事故。这是一家头部实验室主动去塑造管自己的规则。
（来源：IT之家（新浪转载，源 POLITICO），2026-10-17）

### 3. Microsoft 完成 2.8 万亿参数 MAI-Base-2 预训练，称训练效率远超 DeepSeek 同类基座
Microsoft AI 称已完成 MAI-Base-2 的预训练：总参数 2.8 万亿、每 token 激活约 800 亿，用 1.6 万块 GB200 训练 38 天，训练数据约 50 万亿 token 且从一开始就混入视觉数据，目前进入后训练阶段，计划通过 Foundry 向可信伙伴授权权重。其自估训练效率为 DeepSeek-V4-Pro-Base 的 4.2 到 12.3 倍，但这是厂商自测、尚无第三方复现，且模型尚未正式发布。
（来源：Microsoft AI（经 D-CSIL 汇总），2026-10-15）

### 4. NVIDIA 发布 Nemotron 3.5 开源模型家族，120B 多模态 Agent 模型领衔
NVIDIA 推出三款开放模型：120B 的 Super VL 面向能读文本、图像、文档和视频的企业级 Agent，另有两款 Bolt 小模型分别面向本地 24GB 显存设备和边缘设备，前两款已可用、最小一款定于 10 月 23 日推出。权重、数据集与训练配方一并开放，本地就能跑多模态 Agent，对不想把文档送上云的团队是个新选项；性能数字均为厂商口径。
（来源：NVIDIA（经 Harava News 报道），2026-10-16）

### 5. Perplexity 开源 SPACE：支撑其 Computer Agent 的沙箱平台
Perplexity 以 Apache 2.0 开源了 SPACE，这是自 7 月以来支撑其 Computer Agent 每次会话的隔离执行平台：每个任务跑在独立的 Firecracker 微虚拟机里，凭据和网络策略留在虚拟机外，任务可暂停、恢复和分支。Agent 能不能安全地放手干活，沙箱正在变成独立的产品层，这份已在生产环境跑过的实现值得做 Agent 的人翻一翻。
（来源：Perplexity（经 Unite.AI 报道），2026-10-15）
